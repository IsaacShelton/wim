FiraMono Nerd Font Mono (Regular), bundled so file icons work without
installing a font.

FiraMono Nerd Font is Fira Mono (Mozilla Foundation and Telefonica S.A.,
SIL Open Font License 1.1) patched by the Nerd Fonts project
(https://github.com/ryanoasis/nerd-fonts) with icons from several sets.
The font's license is in LICENSE-FiraMono.txt; the icon sets' licenses
(MIT, Apache 2.0, CC BY 4.0) are listed at
https://github.com/ryanoasis/nerd-fonts/blob/master/patched-fonts/FiraMono/README.md
